# Ранний DevOps-период: SWAPP и Azure / EUSY

Этот раздел основан на локальной рабочей копии `eusy-azure`. Исходные приватные репозитории, Terraform state, ключи и сертификаты не публикуются. В портфолио включены только агрегированные метрики и обезличенное описание задач.

## Атрибуция

- `maximturin`, `maximtyurin` и `Maxim Turin` с рабочим email `maxim@hubio.io` — прямые авторские идентичности Максима Тюрина.
- `sirzak` учитывается как подтверждённая владельцем портфолио рабочая учётная запись, под которой он выполнял часть операций.
- Коммиты других авторов не включаются только на основании совместной работы в том же репозитории.

## SWAPP / automation repository

- `941` напрямую атрибутированный коммит за период `2021-12-01` — `2022-07-10`.
- `560` уникальных файлов затронуто в авторской истории.
- Наиболее заметные области: Ansible-роли для балансировщиков и Kubernetes, HashiCorp Vault, Docker, MinIO, Nginx, monitoring, Redis, ClickHouse и сервисы SWAPP.
- В истории присутствуют production/stage inventory, автоматизация развёртывания сервисов, инфраструктурные роли и конфигурация нескольких прикладных контуров.

## Azure / EUSY infrastructure

- `16` напрямую атрибутированных коммитов `maximtyurin` и `2` merge-коммита под подтверждённой учётной записью `sirzak` за период `2022-07-04` — `2022-07-06`.
- `45` уникальных файлов затронуто прямыми авторскими изменениями.
- Подтверждённые зоны работы: Terraform для Azure, HashiCorp Vault, TLS/PKI, DNS, load balancing, PostgreSQL Flexible Server, сети и Ansible-автоматизация.
- Сохранившиеся non-git артефакты дополнительно показывают модули VM, IAM, KMS, load balancer и user data, а также конфигурации Application Gateway, Redis, PostgreSQL и внутренних DNS-зон. Они используются только как подтверждение состава стека, без заявления единоличного авторства.

## Ограничения публикации

- Приватные ключи, сертификаты, пароли, Terraform state и содержимое клиентского кода исключены.
- Метрики не доказывают единоличное создание всей системы: они подтверждают личное участие в перечисленных областях.
- Названия клиентов и внутренние адреса не раскрываются сверх уже использованных в резюме обозначений.
