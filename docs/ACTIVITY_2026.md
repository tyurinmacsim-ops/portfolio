# Инженерная активность: август–октябрь 2026

Работа над инфраструктурой Perx и MyNaghi охватывала Yandex Cloud, AWS, Selectel и bare-metal Kubernetes. Локальный архив Git за период **7 августа — 26 октября 2026** содержит **922 уникальных коммита** автора Maxim Tyurin: 724 обычных и 198 merge-коммитов. В приватном GitLab на **27 октября 2026** профиль автора показывал **210 созданных merge requests, 183 объединённых**. Это след инженерной работы, а не оценка её качества. Рекрутер не сможет открыть приватные исходники или проверить эти числа без доступа.

## Четыре решения, о которых можно говорить на интервью

- **Управляемое IaC.** Разделил GitLab pipeline на validate, plan, контролируемый apply и drift-проверки для OpenTofu/Terraform-стеков. Для приватного Kubernetes API использовал GitLab Agent внутри кластера, не открывая API для внешнего runner. Это подтверждается конфигурацией pipeline и Git-историей; публичные адреса и credentials не публикуются.
- **Безопасный жизненный цикл временных worker-нод.** Для Airflow/importer настраивал ресурсы и параллелизм, масштабирование через Crossplane в Yandex Cloud и AWS. Очистка устаревших Kubernetes Node выполняется только после проверки, что VM уже нет и на ноде не работают пользовательские pod. Это устраняет ложный `KubeDaemonSetRolloutStuck`, не удаляя живые узлы.
- **Мониторинг по причине, а не по симптому.** Разбирал повторные алерты Kubernetes и серверов, уточнял условия правил Prometheus и Grafana. В частности, отделил потерянные временные Node от неисправных DaemonSet и исключил штатное завершение одноразового systemd unit из Critical-алертов.
- **Поэтапные изменения на хостах.** Обновил Traefik на 22 Selectel-ВМ последовательно и проверил состояние контейнеров. Участвовал в восстановлении сайтов после сбоя зон Yandex Cloud и подготовке переноса сервисов на Selectel; **подготовка переноса не означает, что миграция завершена**.

Смежные задачи: GitLab Runner и приватный доступ через NetBird, Ansible/Helm/Argo CD, секреты и сетевые политики, публикация MyNaghi через S3/CloudFront. Они не вынесены в отдельные «достижения», чтобы не раздувать резюме.

## Методика и ограничения

Скрипт [`scripts/build_perx_summary.py`](../scripts/build_perx_summary.py) читает локальные Git-истории, выбирает коммиты с точным именем автора `Maxim Tyurin`, дедуплицирует по SHA и отдельно считает merge-коммиты. Архив содержит повторные рабочие копии одних историй, поэтому число каталогов и появлений коммита в каталогах не равно числу независимых проектов или выполненных задач. GitLab-числа — отдельный снимок фильтра по автору, не сумма с commit-метриками. Даты коммитов не подтверждают срок трудоустройства. Исходные репозитории, адреса ресурсов и приватные merge requests здесь не публикуются.
