# Инженерная активность: август–октябрь 2026

Работа над инфраструктурой Perx и MyNaghi охватывала Yandex Cloud, AWS, Selectel и bare-metal Kubernetes. Локальный архив Git за период **7 августа — 26 октября 2026** подтверждает **922 уникальных коммита** автора Maxim Tyurin: 724 обычных и 198 merge-коммитов. Это отдельный архив, который не включён в более раннюю статистику сайта; складывать показатели без повторной сверки историй нельзя. Даты ниже — даты коммитов, а не официальные даты трудоустройства.

## Задачи и результаты

- **IaC и delivery:** OpenTofu/Terraform для сетей, ВМ, Kubernetes и managed PostgreSQL в Yandex Cloud; GitLab pipeline с проверками, plan, контролируемым apply и контролем расхождений.
- **Kubernetes и GitOps:** Ansible, Helm и Argo CD для production и dev/stage; настройка секретов и сетевых политик через Vault, External Secrets, Cilium, Traefik и NetBird.
- **Временные workers:** масштабирование Kubernetes worker-нод через Crossplane для Yandex Cloud и AWS, безопасная очистка устаревших Node.
- **Наблюдаемость:** Prometheus/Grafana, метрики и алерты; уточнение условий срабатывания для устранения повторных ложных уведомлений.
- **Data workloads:** Airflow и importer — параллелизм, requests/limits, размещение pod'ов и поведение workers при масштабировании.
- **Хосты и приложения:** последовательные изменения на 22 Selectel-ВМ с обновлением Traefik; Docker Compose/TLS для Finance System и S3/CloudFront-публикация сайта MyNaghi.

Часть формулировок выше дана владельцем портфолио; Git-история подтверждает технические направления и активность, но не доказывает причинно-следственную связь или бизнес-эффект каждого изменения. Конкретные результаты и степень личной ответственности лучше разбирать на интервью по обезличенным примерам.

## Методика и ограничения

Скрипт [`scripts/build_perx_summary.py`](../scripts/build_perx_summary.py) читает локальные Git-истории, выбирает коммиты с точным именем автора `Maxim Tyurin`, дедуплицирует по SHA и отдельно считает merge-коммиты. Архив содержит повторные рабочие копии одних историй, поэтому число каталогов и появлений коммита в каталогах не равно числу независимых проектов или выполненных задач. Даты взяты из Git-истории; это не подтверждение периода трудоустройства. Исходные репозитории приватные и здесь не публикуются.
